行列輸入法鍵碼表 2026 擴增規劃
===

行列輸入法鍵碼表自從 2023 年 2 月釋出符合 Unicode 14.0 規格，且完整支援中日韓統一表意文字（CJK Unified Ideograph，以下簡稱 CJK）Ext-G 範圍的版本 v2023-1.0 之後，已歷時 3 年。截至目前為止，Unicode 17.0 業已釋出，蒐錄 CJK 字集範圍已擴增至 Ext-J，這是本人決定為行列輸入法再次擴增字碼的初衷。

然而，擴增支援字集的事情這次不會這麼簡單，因為以往大家敬愛的行列大家長廖明德大哥，以退休調養身體為重，在廖大哥尚未回歸之前，主要將由本人獨力進行，所以本次的行列輸入法擴增字集的方式，將與以往所有不同。

2026 擴增草案
---
目前我已初步完成 CJK Ext-H/I/J 的編碼（大約新增九千字），主要是以「全人工」方式，並參考行列 v2023-1.0 版本的字根表進行（包括簡體字根表，可自我的 github 頁面下載），而非以往由廖大哥跑程式自動產生（含容錯碼）再由本人協助校訂。這在傳統上支援容錯的行列輸入法上，就會出現下列困擾：
1. 首先，對於同一個字，每位朋友可能有各自的拆解方法，但因這次以人工方式進行，部分漢字可能會遷就本人的輸入習慣（或許會和您習慣拆碼的方式不同），為了降低這種情形，這次在支援字集擴充上我盡可能的回歸本字（也就是依據教育部的正體字筆順，不管異體字；亦即暫不考慮容錯問題，每個字只有唯一的解碼方式）。
2. 再者，人工作業錯誤在所難免，所以我將目前的成果放在 github 頁面上「公測」，歡迎眾行列之友下載檢視，大家共同參與，不分你我，大家一起來持續維護行列輸入法，直到大家敬愛的廖大哥回歸後，再將容錯碼補齊。

行列輸入法擴增改版，需要您的協助
---
上面說這麼多，那麼要如何參與校訂行列輸入法字碼呢？

1. 首先，您需要一個能顯示 CJK Ext-H/I/J 的字型。我推薦 Jigmo 字型（釋出日期 20250912，下載連結 https://kamichikoichi.github.io/jigmo/Jigmo-20250912.zip ），內含三套字型檔 Jigmo/Jigmo2/Jigmo3，請將它們全都安裝到您的系統（Windows/macOS/Linux 皆可）。
2. 接下來，請下載本頁面 .ods 副檔名的試算表檔案，使用 Microsoft Excel 或 LibreOffice Calc 等試算表軟體開啟即可。

如果您發現我在某些字的行列鍵位拆解結果有誤，歡迎在 github 留言或者在 [Facebook 行列輸入法社群](https://www.facebook.com/groups/517104371955479)回報我更正，讓這個好用的輸入法永續傳承下去。
