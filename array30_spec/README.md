# 行列30 輸入法規格書（2017 年版）

本規格書專為輸入法軟體作者撰寫，它最初由行列科技廖明德先生（即行列輸入法發明人）公開於行列輸入法官網「行列輸入法的家」，因為該官網業已關閉，故由本人重新上傳於此，歡迎有意植入行列30 輸入法的程式設計師多加參考。

1. 為忠實還原 2017 年規格書當時之原貌，特保留當時的行列30 符號表版本供參。
2. 行列30 符號表於 2017 年之後，已於 v2023 及 v2026 再歷經 2 次更新（含新增第二符號表 HG，6- 5-）；輸入法軟體於植入行列30 時，建議以此最新版本為準。

### 行列詞庫

行列詞庫 (`array30-phrase.txt`)，目前蒐錄約 6 萬個詞彙，原收錄於需付費的「行列詞彙輸入法」軟體，經行列輸入法發明人廖明德先生同意公開於此處，並無償授權提供各家第三方輸入法軟體作者，提供開發行列輸入法軟體時採用。更新歷程說明如下：

* 2026/07/23 修正 [#19](https://github.com/gontera/array30/issues/19) 的錯誤，感謝 Limeroshenko 指正。
* 2026/05/28 補足原始詞彙碼表中有定義，但本站於 2021 年釋出時漏列的半形標點符號 , . ; /。
* 2021/07/25 刪除「行列詞彙輸入法」原始詞庫中的重複詞彙，於本站首次釋出。
