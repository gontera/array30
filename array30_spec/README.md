# 行列30 輸入法規格書（2017 年版）

本規格書專為輸入法軟體作者撰寫。最初由行列科技廖明德先生公開於行列輸入法官網「行列輸入法的家」，因為該官網業已關閉，故由本人重新上傳於此，歡迎有意植入行列30 輸入法的程式設計師多加參考。

檔案說明
---
* ar30portingSpec.txt：行列30 輸入法規格書
* ar30hw.txt：一、二級簡碼之合併檔
* ar30SpecialCodes.txt：行列30 特別碼
* ar30symbol.txt：行列30 符號表(W)（*註）

*註：上述行列30符號表**係 2017 年的版本**，為忠實還原 2017 年當時之規格原貌，特保留供參。行列符號表後續已於 v2023 及 v2026 再歷經 2 次更新，故行列30符號表的最新內容，**應以本站釋出的行列30 輸入法「標準版」或「大字集版」 .cin 檔為準**。
